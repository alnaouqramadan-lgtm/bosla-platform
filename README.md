# بوصلة AI | BOSLA AI

منصة مستقلة للتخطيط الاستراتيجي والتشغيلي وإدارة الورش التشاركية، مبنية باستخدام Next.js 15 وReact 19 وSupabase.

## حالة الإصدار
- المصدر الحالي: **v0.1.1 (اختباري)**؛ نقل أولي مستقل إلى مستودع `bosla-platform`.
- قاعدة بيانات Supabase المستقلة: مشروع `madvrkqtducoivnaaldm` في مؤسسة BOSLA AI.
- ترحيلان مطبقان بالفعل على هذا المشروع، وموجودان في `supabase/migrations/`. **لا تعِد تطبيقهما يدويًا** على قاعدة البيانات الحالية.
- 8 جداول مع Row-Level Security، و15 فهرسًا للمفاتيح الأجنبية. تم اختبار رفض كتابة غير مصرّح بها.
- اختبارات `npm test` البنيوية ناجحة. لم ينجح بعد التحقق من `npm run typecheck` و`npm run build` لأن التبعيات غير مثبتة محليًا.
- النسخة الأحدث المشار إليها في مكتبة الملفات `v0.2.1-beta` لم تتوفر محتوياتها للدمج، لذا هذه ليست النسخة الأحدث، ولا تُعد إصدارًا إنتاجيًا جاهزًا.

## الوظائف الموجودة في الشفرة
- واجهة عربية RTL، إنشاء حساب وتسجيل دخول مستقلان عبر Supabase Auth.
- إنشاء مؤسسات وورش ومجموعات، دعوات مشاركة برمز طويل، وتحديد الميسر والمقرر.
- خمس مراحل تخطيطية تضم 28 حقلًا، حفظ إجابات، فتح/إغلاق مراحل، تصويت على الأولويات.
- تجميع للقضايا المتطابقة، وعرض وطباعة النتائج، وتصدير Excel.

## إعداد بيئة التشغيل
1. استخدم مشروع Supabase المستقل فقط. لا تستخدم مشروع إنجاز أو مفاتيحه.
2. في Vercel أو `.env.local` محليًا عيّن:
   - `NEXT_PUBLIC_SUPABASE_URL=https://madvrkqtducoivnaaldm.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY=<public publishable-or-anon-key from BOSLA>`
3. لا تُدخل `service_role` أو مفتاحًا سريًا في متغير `NEXT_PUBLIC_` أبدًا.
4. شغّل `npm install`, ثم `npm test`, ثم `npm run typecheck`, ثم `npm run build`.
5. بعد إنشاء نشر Vercel مستقل، اضبط رابط الموقع في Supabase Auth URL Configuration وRedirect URLs.
6. نفّذ سيناريوهات `tests/ACCEPTANCE.md` قبل الإطلاق أو دعوة المؤسسات الحقيقية.

## الحدود والصلاحيات
يعمل BOSLA AI بمستودع وقاعدة بيانات ومصادقة مستقلة عن ENJAZ AI؛ لا تجرِ تعديلات على `enjaz-ai` ولا تشارك جداول أو مفاتيح Supabase بين التطبيقين. جميع جداول التطبيق ذات RLS، لكن لا بد من اختبارات قبول متعددة المستخدمين قبل الاستخدام الفعلي.

- تهيئة Vercel مستقل وربط إعدادات Authentication.
- مراجعة ودمج النسخة الأحدث `v0.2.1-beta` قبل اعتماد الإنتاج.
